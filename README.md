# אתר שעון — LUMA CRAFT

אתר לבוטיק שעונים בדיוני בשם **LUMA CRAFT**. בונים אותו שלב אחרי שלב.

- `v0-claude-draft` (git tag): טיוטת הקונספט הראשונה, עם שעונים בתלת־ממד
- `main`: הבנייה החדשה (v1)

## הרצה מקומית

```bash
python tools/devserver.py 5173
```

ואז לפתוח את http://localhost:5173

## מה יש עכשיו (v1)
- נאבבר צף בשחור עמוק, עם הבזק אור דינמי שעוקב אחרי העכבר
- לוגו זמני (SVG): LUMA רחב ונמוך עם A אדומה, ומתחתיו CRAFT
- שלושה פרקים באותו מבנה כמו ב־v0 (טקסט מימין, במה משמאל), עם placeholders
- אזור שמור לדף הפניות

הצבעים והפונטים מוגדרים כ־tokens בראש `css/style.css`.
